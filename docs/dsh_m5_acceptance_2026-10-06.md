# DSH M5 长会话问题导航验收

日期：2026-10-06。对应 `dsh_frontend_development_plan.md` 的 M5，不混用较早产品体验方案的 M 编号。

## 改动与解决的问题

- 目录身份由最新尝试的消息 ID 改为稳定重试组；新增尝试保留同一入口，并跳到最新尝试。展开旧尝试后，当前项也能映射到所属问题组。没有重试关系的相同问题仍分别显示。
- 修正跳转的滚动容器坐标。跳转立即暂停自动跟随；草稿分片及正式回答到达时不拉回底部，回到最新后恢复跟随。
- 保留完整问题文本，以 CSS 缩略目录行；悬停/聚焦显示完整问题预览。增加方向键、Home/End、Escape、焦点恢复、外部点击关闭及会话切换清理。移动端按钮至少 44px，弹出目录内部滚动。
- 保留现有历史接口和重试请求语义，针对已加载历史；没有新增分页、模型调用或虚拟列表。
