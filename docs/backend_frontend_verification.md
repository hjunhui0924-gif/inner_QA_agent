## 修复前证据与原因

初次联调 `work/backend-verification/live-20260912-230234/report.json` 为 9 项通过、4 项失败：RAG 首轮及追问缺引用，联网回答返回查询 JSON，DuckDuckGo Instant Answer 返回空摘要和空来源却被工具判成功。旧失败记录保留为基线，不代表当前状态。

## 本轮修复

1. **真实 Chroma 入库失败**：分块元数据中的默认空 ACL 数组触发 Chroma `Expected metadata list value ... to be non-empty`，导致上传 HTTP 400。写入时省略空数组，保留非空 allow/deny 列表；JSON 原记录仍保留权限信息。新增真实 Chroma 回归测试，验证写入、检索及非空权限列表往返；完整后端回归通过。
2. **详情正文未加载**：列表接口不提供正文，前端此前未调用详情接口。现已接入 `/knowledge/records/{source_id}`，读取 `record` 响应包裹，增加加载状态、错误重试和过期响应保护，优先展示详情正文。通过组件、接口契约及真实浏览器验证。
3. **RAG 漏引用**：比较模型后，将生成与 Judge 默认及本地配置切换为 `qwen3.8-flash`，保留引用与语义校验。引用失败提示改为“已找到相关资料，但暂未生成可验证的回答”，不伪装成检索无结果。
4. **联网无效结果**：改用 DashScope 原生搜索，直接复用带来源的回答，减少额外生成调用。无来源、无效答案、服务失败分别返回稳定错误；前端给出对应提示和适用的重试入口。
5. **真实联调扩展发现的问题**：通用模式使用独立提示词，避免继承企业知识库限制；知识不足时提示补充资料。搜索 SSE 增加字节上限、超时、截断拒绝、引用范围及失败用量测试；独立代码复核发现的三项问题均已修复并回归。

确定性 generation_failure 在本次均为短语匹配失败，不是模型调用失败。例如答案使用法规全名替换“本法”，日期正确也会被严格短语指标扣分。真实剩余问题包括：`dsl_05` 漏掉“及时告知用户”，自动 Judge 判不完整；`genai_02` 的首句“不适用。”缺独立引用，后文有引用，仍保留引用失败。没有放宽评判规则或人工覆盖失败结果。

该开发集参与过迭代，且生成与 Judge 使用同模型；97.06% 不等于独立人工准确率。脚本不经过完整 Agent 的路由、重试与安全降级，也未在本轮重跑三套数据的统一质量门禁。下一阶段优先改善多条义务的完整覆盖，并增加独立模型或人工留出集评判。
