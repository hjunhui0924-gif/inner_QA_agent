## 配置口径

本轮实测使用 DeepSeek v4 Pro 生成及 Judge、`CITATION_VALIDATION_MODE=judge`、Tavily basic 搜索。仓库 `Settings` 缺省值仍保留 DashScope/Qwen 和 `legacy`，避免把特定供应商的验证结论强制应用于所有部署；本地配置优先于这些缺省值。生成与 Judge 使用同一模型的自评偏差仍存在。

本轮没有修改实际 `.env`、日常知识库/会话或账号设置，没有提交、推送或部署。
