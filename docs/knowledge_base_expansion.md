# 企业知识库扩充记录

更新时间：2026-09-18。

本轮将可复现的企业测试知识库从 25 条扩充到 50 条记录，并将原有文档和新增文档统一整理为同一套元数据。新增资料不是某一家公司的真实制度，而是根据公开法规、监管机构公开信息和企业流程常见结构整理的合成测试材料；每条记录都保留 `reference_type=public_reference_synthesis`、参考标题和参考网址，避免把公开法规摘要误称为企业内部制度。

## 配套评测题

`data/evals/enterprise_rag_eval.json` 现在包含 414 道结构化题：

- 329 道可回答题、85 道无答案题；无答案比例约 20.5%。
- 每条新增文档配 5 道可回答题和 1 道无答案题，共新增 150 道。
- 新题覆盖直接事实、条件规则、阈值、流程、多步骤、否定规则和拒答。
- 新题分布在 `development`、`regression`、`held_out` 三个 split；现有题目 ID、来源和期望事实均保留。
- 所有新增 `evidence_phrases` 都经过脚本对照文档正文验证，避免题目引用不存在的内容。

可重复生成和校验的入口是：

```powershell
python scripts/expand_enterprise_knowledge.py
python scripts/run_enterprise_rag_benchmark.py --top-k 5
```

扩充脚本是幂等的，会按稳定 ID更新新增内容并重算 checksum，不会重复追加文档或问题。离线评测使用确定性 hashing embedding 和 token-overlap reranker；它衡量检索覆盖，不等同于真实模型回答质量。正式模型问答仍需单独运行在线评测，并保留独立留出集。

本轮扩充后的离线回归结果：50 条文档、414 道题，回归门禁通过；全量 Source Hit@5 为 94.74%，Evidence Recall@5 为 94.74%，无答案证据代理准确率为 100%，检索失败数为 2。完整报告写入被忽略的 `work/knowledge-expansion-enterprise-benchmark.json`，不会覆盖仓库已有评测报告。

`data/eval_reports/enterprise_rag_benchmark.json` 已更新为本轮 50 条文档、414 道题的离线确定性报告。统一 456 题在线报告需要重新付费调用向量和重排服务；本轮长时间尝试未完成，因此保留仓库原有的在线报告，不把离线 smoke 结果伪装成在线质量结论。要刷新统一在线报告，执行 `python scripts/run_unified_rag_benchmark.py --mode retrieval`，完成后应检查 `offline=false`、`case_count=456` 和各数据集门禁。

## 使用边界

这些资料适合验证知识助手的索引、版本、权限、引用、无答案拒答和多业务检索流程。它们不代表任何真实公司的制度，也不应直接作为员工政策、财务审批依据或法律意见。部署到真实企业前，应替换为经过授权、脱敏和版本确认的内部文件，并重新标注来源、有效期、访问权限和责任人。
